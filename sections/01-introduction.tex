\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{W}{ildfires} threaten ecosystems, infrastructure, and human safety
\cite{bowman2020wildfire}. Unmanned aerial vehicles (UAVs) can rapidly observe
hazardous and inaccessible areas through flexible aerial sensing
\cite{allan2022remote}. Effective response, however, requires more than
observation: aerial evidence must be converted into task zones, assigned across
a resource-limited fleet, and reconsidered as the fire or UAV state changes.
Multi-UAV wildfire response is therefore a closed-loop mission-coordination
problem rather than an isolated perception, navigation, or allocation task.

An initial mission must be feasible for the current fleet. Task priorities must
be matched to vehicle locations, endurance, payload, communication, and safety
limits \cite{floreano2015science}. This feasibility is temporary: fire
evolution, resource consumption, communication changes, and UAV faults can
invalidate existing assignments. Initial mission planning under resource
constraints and runtime plan repair must consequently be treated as coupled
stages of the same decision process. A useful coordination system must both
establish initial feasibility and preserve mission continuity after the
operational state changes.

Existing research provides many capabilities needed for this process. UAV
disaster-response and wildfire studies cover sensing, fire perception,
exploration, coverage, cooperation, and task planning
\cite{erdelj2017help,akhloufi2021wildlanduav,
boroujeni2024aiwildfiresurvey}. Representative advances include thermal--RGB
fire detection \cite{yuan2021uavfire}, autonomous disaster exploration and
mapping \cite{popovic2021uavdisaster}, coverage planning
\cite{yu2022coverageuav}, and multi-UAV task allocation and search-and-rescue
coordination \cite{yang2023multiagentuav,baker2016uavsar}. Integrated
systems have also coupled wildfire situation assessment and spread prediction
with multi-UAV observation planning \cite{bailonruiz2022realtimewildfire}, and
dynamic wildfire models have informed cooperative coverage and tracking under
limited fleet resources \cite{seraj2022wildfireplanning}. These results
establish that sensing and planning can be integrated. However, existing studies
address different response objectives using task-specific inputs, state
representations, action spaces, resource assumptions, and evaluation protocols.
Their reported results therefore do not directly establish how initial
mission planning and runtime plan repair behave under common resource bounds and
perturbation conditions.

Large language models (LLMs) offer a flexible high-level interface for such
coordination. SayCan grounds language instructions in executable skills
\cite{ahn2022saycan}, Code as Policies generates programmatic control policies
\cite{liang2023codeaspolicies}, and embodied multimodal models connect visual
evidence and robot state to reasoning \cite{driess2023palme,zeng2023socratic}.
LLMs have also been used for multi-robot task decomposition, coalition
formation, and allocation \cite{kannan2024smartllm}. Environmental feedback can
support plan revision \cite{huang2023innermonologue}, while prior experience
can inform subsequent decisions \cite{wang2023voyager}.
Prior execution experience has also been used to explain failures and provide
references for subsequent plan revision \cite{liu2023reflect}. These
mechanisms are relevant to heterogeneous wildfire observations, fleet
operational states,
constraints, and structured task chains. Their flexibility does not, however,
guarantee an executable mission: a linguistically coherent plan may omit a
zone, reference an unavailable UAV, or violate payload, endurance, or structural
constraints, and a one-shot plan cannot account for later state changes.
Validator-guided iterative refinement has consequently been introduced to
improve the feasibility and correctness of long-horizon LLM-generated plans
\cite{zhou2024isrllm}. Explicit validation and execution feedback are therefore
necessary to turn LLM reasoning into usable mission coordination.

This setting raises three linked requirements. First, aerial observations must
be converted into a structured task representation for fleet-level planning.
Second, an initial mission plan must be generated and checked against resource, safety,
and structural constraints, with relevant prior mission records available as
planning references. Third, when a runtime perturbation changes the fire
situation, fleet operational state, resources, or schedule, the affected part
of the active plan must be
repaired locally. Studying these requirements together also calls for a common
evaluation setting in which initial mission planning, plan validation,
experience retrieval, and runtime plan repair share the same resource bounds, perturbation
conditions, and mission-level metrics.

To meet these requirements, we develop CLoMC-UWR (Closed-Loop Mission
Coordination System for UAV Wildfire Response), an LLM-based closed-loop
mission-coordination system. Vision Analysis converts aerial observations into
fire points and task zones, and Mission Planning maps the structured fire
situation, UAV operational states, and mission constraints into an initial
multi-UAV task plan.
Validation prevents tactically implausible or structurally invalid plans from
entering execution. Memory retrieves similar prior task situations together
with their associated plans and execution outcomes. Runtime Replanning uses the
updated operational state to repair the affected part of an active plan. In
this way, CLoMC-UWR turns one-shot LLM planning into a validated and
feedback-driven mission-coordination loop.

We evaluate this loop in a real-UAV-informed AirSim suite with common fleet
constraints and controlled runtime perturbations. Four difficulty levels
progressively increase resource, scheduling, and perturbation pressure, while
six mission-level metrics distinguish task completion, execution quality, and
mission continuity. Under this protocol, we examine end-to-end behavior,
identify the condition-dependent roles of Validation, Memory, and Runtime
Replanning, and assess whether validated demonstrations can transfer initial
planning behavior to a compact planner with lower overhead.

The main contributions of this work are summarized as follows:
\begin{enumerate}[leftmargin=1.6em,itemsep=2pt,topsep=3pt]
    \item We formulate resource-constrained multi-UAV wildfire response as a
    closed-loop mission-coordination problem and develop CLoMC-UWR, which
    connects aerial fire-situation understanding, initial mission planning,
    explicit plan validation, experience retrieval, and runtime plan repair
    through an explicit task model.
    \item We construct a real-UAV-informed AirSim evaluation suite that examines
    initial mission planning and runtime plan repair under shared fleet constraints and
    controlled perturbations, using four levels of operational pressure and six
    mission-level metrics covering task completion, execution quality, and
    mission continuity.
    \item Under this common protocol, we compare end-to-end decision approaches,
    characterize the condition-dependent roles of Validation, Memory, and
    Runtime Replanning, and assess whether validated demonstrations can transfer
    initial mission planning behavior to a compact planner with lower planning overhead.
\end{enumerate}
